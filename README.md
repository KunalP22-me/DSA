## 🧮 Common DSA Templates (Quick Recall)

### Binary Search

```
mid = l + (r - l) / 2
```

### Two Pointer

```
l = 0; r = n - 1;
while (l < r) {
   // move pointers based on condition
}
```

### Kadane’s Algorithm

```
curr = Math.max(a[i], curr + a[i]);
ans  = Math.max(ans, curr);
```
